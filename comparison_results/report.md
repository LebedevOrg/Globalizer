## Настройки методов

- **GLZ-native**: PYDGlobalizer.solve: r=4, eps=0.01, max_iterations=B, локальный поиск при улучшении минимума.
- **GLZ-scipy**: globalizer.optimize.differential_evolution(maxfev=B), параметры по умолчанию.
- **GLZ-optuna**: globalizer.optuna: create_study() по умолчанию (GlobalizerSampler), n_trials=B.
- **SciPy-DE** (стохастический): scipy differential_evolution: popsize=15, maxiter=B/(15*n), polish=False.
- **SciPy-DA** (стохастический): scipy dual_annealing(maxfun=B) - только задачи без ограничений.
- **SciPy-DIRECT**: scipy direct(maxfun=B) - только задачи без ограничений.
- **SciPy-SHGO**: scipy shgo: sobol, n=min(128, B/8), maxfev=B.
- **Optuna-TPE** (стохастический): optuna TPESampler(seed), ограничения - trial.set_constraint.
- **Optuna-CMA** (стохастический): optuna CmaEsSampler(seed) - без ограничений (нужен пакет cmaes).
- **Optuna-Random** (стохастический): optuna RandomSampler(seed) - базовый уровень.

## Как читать результаты

- Все методы получают одну и ту же функцию со счётчиком; учитываются первые B вычислений одного запуска. Метод, который тратит вычисления в конце (финальное локальное уточнение), при бюджете B его не получает: так у GLZ-scipy (локальный поиск после глобального, `maxfev` ограничивает только глобальную фазу) и поэтому у SciPy-DE отключён `polish`.
- Точка, в которой метод проверил ограничение и не стал вычислять критерий, тоже считается вычислением (так считают и Globalizer, и SHGO/DE).
- Методы, не соблюдающие свой лимит, прерываются после 2·B+100 вычислений или 120 с; результат считается по накопленной истории: circle/SciPy-SHGO, g08/SciPy-SHGO, rastrigin2/SciPy-SHGO, rosenbrock3/SciPy-SHGO.
